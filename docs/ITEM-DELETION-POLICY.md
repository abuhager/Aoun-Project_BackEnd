# سياسة حذف الأغراض والمراجع

الغرض الذي يرتبط بمحادثة أو بلاغ أو تقييم لا يُحذف فعليًا من MongoDB. مسارا
الحذف (المالك والإدارة) يحولانه إلى tombstone بحالة `محذوف` ويسجلان
`deletedAt` و`deletedBy` و`deletionReason` داخل transaction واحدة.

- القوائم العامة وتفاصيل الغرض لا تعرض tombstones.
- المحادثات المرتبطة تُؤرشف وتصبح للقراءة فقط، مع بقاء سجل الرسائل.
- البلاغات والتقييمات وطلبات التبرع تحتفظ بمراجعها لأغراض النزاهة والتدقيق.
- حذف صورة Cloudinary يمر عبر outbox مشفر وقابل لإعادة المحاولة؛ وبعد النجاح
  تُمسح `imageUrl` و`cloudinaryId` من tombstone.
- شغّل `npm run db:orphans:audit` دوريًا وبعد أي migration. رمز الخروج `2`
  يعني وجود مراجع يتيمة ويلزم التحقيق، والأداة لا تعدّل البيانات.

مدة الاحتفاظ النهائية والحذف القانوني تخضعان لمصفوفة الاحتفاظ المعتمدة من
الجهة القانونية؛ لا يجوز hard-delete جماعي قبل اعتمادها واختبار الاستعادة.
